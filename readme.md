# interfaz de estadisticas y diseño visual

El presente trabajo consiste en el desarrollo de una interfaz web
que permite visualizar estadísticas mediante componentes 
estilizados. La propuesta se centra en la aplicación de HTML y CSS
 para estructurar y dar formato a elementos como tarjetas, fondos
  personalizados y barras de progreso
  ___________________________________________________
  
 Se utilizó HTML para la construcción de la estructura básica de la
   interfaz y CSS para la definición de estilos, colores,
    tipografías y disposición de los elementos. Además, se añadieron
     propiedades específicas para personalizar componentes como el
      < progress > y se trabajó con flexbox para lograr una
       distribución equilibrada.
